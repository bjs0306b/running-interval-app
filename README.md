# 4-5주차 오픈 미션: 런닝 인터벌 앱

## 기능 목록

### 0. 메인 레이아웃 및 공통 기능

- [x] React Router를 사용하여 페이지 라우팅을 구현한다.
- [x] 공통 헤더 및 푸터를 구현한다.
  - [x] 헤더에 '러닝 인터벌 앱' 타이틀을 표시한다.g
  - [x] 푸터에 '러닝' 페이지와 '기록' 페이지로 이동할 수 있는 네비게이션(탭)을 구현한다.

### 1. 러닝 페이지 (메인 타이머)

- [x] 기본 UI
  - [x] 메인 타이머 화면을 표시한다.
  - [x] '시작' (또는 '일시정지'), '설정', '리셋', '음소거' 버튼을 표시한다.
- [x] 설정 기능 (모달)
  - [x] '설정' 버튼 클릭 시, 설정 모달 창을 연다.
  - [x] '달리기' 시간을 분(min) / 초(sec) 단위로 설정할 수 있다. (기본값: 2분 0초)
  - [x] '휴식' 시간을 분(min) / 초(sec) 단위로 설정할 수 있다. (기본값: 1분 0초)
  - [x] '반복 횟수'를 설정할 수 있다. (기본값: 3회)
- [x] 타이머 핵심 로직
  - [x] '시작' 버튼을 누르면 '중지'(혹은 '일시정지') 버튼으로 텍스트가 변경된다.
  - [x] 설정된 '달리기' 시간부터 타이머가 1초씩 감소한다.
  - [x] '달리기' 시간이 0초가 되면, '휴식' 시간으로 상태가 자동 전환된다.
  - [x] '휴식' 시간이 0초가 되면, '달리기' 시간으로 상태가 자동 전환된다.
  - [x] 설정된 '반복 횟수'를 모두 완료하면 타이머가 최종 종료된다.
- [x] 알림 기능
  - [x] '달리기' ↔ '휴식' 상태가 전환될 때마다 알림음(e.g., "삑")을 재생한다.
  - [x] '음소거' 버튼을 누르면 알림음이 꺼지고, 대신 '진동'(Vibration API)으로 알림을 대체한다.

### 2. 기록 페이지

- [ ] 페이지 라우팅
  - [ ] '러닝' 페이지와 '기록' 페이지를 전환할 수 있는 네비게이션(탭)을 구현한다.
- [ ] 기록 조회
  - [ ] 완료된 러닝 세션의 기록(e.g., 날짜, 설정값)을 목록 형태로 조회할 수 있다.
- [ ] 데이터 영속화
  - [ ] 완료된 러닝 기록을 브라우저의 '로컬 스토리지(Local Storage)'에 저장하여, 새로고침해도 기록이 유지되도록 한다.
